프로젝트 1

영어 어휘 학습을 위한 의미 기반 이미지 생성 및 학습 관리 시스템

이 프로젝트는 두 가지 주요 기능을 제공합니다. 첫째, 사용자가 입력한 영어 단어에 대한 의미 기반 이미지를 생성하여 시각적 학습을 지원합니다. 둘째, 사용자가 학습한 단어를 관리하고 복습할 수 있는 시스템을 제공합니다. 두 개의 마이크로 서비스로 구현되어 있으며, 각 기능은 독립적으로 운영될 수 있고, 각 서비스는 RESTful API를 통해 통신합니다. 또한, 사용자 인터페이스는 직관적이고 사용하기 쉽게 설계되어 있어 학습 경험을 향상시킵니다.


기술 스택 (Tech Stack)

  • Microservices Architecture: 기존 학습 서비스와 AI 이미지 생성 서비스를 독립 Spring Boot 애플리케이션으로 분리하여 각각의 REST API 및 포트로 구성
  • Spring Boot (Java): REST API 및 단어 의미·시각화 생성 로직 구현
  • Spring Data JPA / MySQL: Word → WordSense → VisualConcept → VisualImage 도메인 모델링 및 데이터 저장
  • Spring AI / OpenAI API: 의미별 VisualConcept 생성 및 AI 이미지 생성 파이프라인 구현
  • React: 단어의 다중 의미 선택 및 의미별 시각화 이미지 학습 UI 구현
  • Axios: 프론트엔드와 복수 Spring Boot 서비스 간 REST API 통신
  • Git / GitHub: 버전 관리 및 프로젝트 소스 관리

구조 (Structure)

AI 기반 Visual Image 생성 서비스

  • 하나의 영어 단어에 대해 복수의 의미(WordSense)를 생성하고 데이터베이스에 저장
  • 각 WordSense의 definition을 기반으로 의미에 대응하는 VisualConcept 생성
  • VisualConcept을 이미지 생성 모델에 전달하여 학습용 이미지를 생성하고 이미지 URL 및 메타데이터 저장
  • Word → WordSense → VisualConcept → VisualImage 구조로 의미별 시각화 데이터 관리

단어 시험 및 학습 관리 서비스

  • 사용자가 학습 및 시험을 진행할 단어장과 회차를 선택할 수 있는 기능 제공
  • 시험 방식 선택 및 단어 테스트 진행 기능 구현
  • 사용자별 학습 진행 상황과 시험 결과를 데이터베이스에 저장 및 관리
  • Visual Image 생성 서비스와 연동하여 단어의 의미별 시각 자료를 학습 과정에 제공

서비스 구성

  • Microservices Architecture: 학습·시험 관리 서비스와 AI 기반 Visual Image 생성 서비스를 독립적인 Spring Boot 애플리케이션으로 분리
  • 각 서비스가 독립적인 REST API를 제공하도록 구성하고 React 클라이언트에서 Axios를 통해 연동
